# Starter kit

Livingit's starter kit: a SvelteKit app with Postgres, better-auth, an example page and Claude Code skills for working
a customer's issues through Agentic Studio. It runs on your machine from a few commands, and from the first day the
code is the team's.

## Make your app from it

1. On GitHub, choose **Use this template** and make the app's repo.
2. Clone it, and name the app once. This fills in the docs, the package name and the app's name, and puts the app's own
   README here:

   ```sh
   bun install
   bun run name "Kundportalen"
   ```

3. Commit what it wrote, then follow [docs/getting-started.md](docs/getting-started.md).

## With Agentic Studio

The skills in `.claude/` work the customer's issues through Agentic Studio's MCP server. The address, the command to
add it and how to install the agent kit are under **Agenter** in Agentic Studio.
